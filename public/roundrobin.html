How this works

Each new layer halves in step density — 32nd, 16th, 8th, quarter, half, whole — so every instrument you add lands on a subset of the grid before it. Click cells to toggle any step by hand. "Generate Section B" thins the melodic layers and foregrounds bass/kick while busying the hi-hat, and "Play Song Form" auto-arranges A·A·B·A. Save the whole layer set plus tempo, then load it back any time.
