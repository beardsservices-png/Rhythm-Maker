How the song grid works

Each row is an instrument; each block is a section. The letter at the start of a block is which pattern that instrument plays there — click it to change (A → B → C → D → silent). S solos that instrument for that section only. Click or drag across bars to mute just those bars, or pick A–D above and drag to paint a pattern in. Loop parts loops whatever each instrument is set to; Play song plays the sections in order.

One reverb and one delay shared by everything; the rev and dly sliders on each mixer strip decide how much of that track goes in. The delay follows the tempo.
